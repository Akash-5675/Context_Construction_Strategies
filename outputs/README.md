# outputs/

All experiment results and publication-ready figures.

## Files

| File | Created by | Description |
|------|-----------|-------------|
| `all_results.csv` | `src/experiment_runner.py` | One row per (question × condition × embedding_model × k). ~13,600 rows for a full run. |
| `summary.csv` | `src/analyze.py` | Aggregated mean ± SD per condition across all metrics. |
| `summary_anova.csv` | `src/analyze.py` | One-way ANOVA F-statistics and p-values per metric across all conditions. |

## all_results.csv columns

| Column | Type | Description |
|--------|------|-------------|
| `run_key` | str | Unique run identifier: `{q_id}__{condition}__{model}__k{k}` |
| `question_id` | str | From questions.csv |
| `topic` | str | Medical topic |
| `condition` | str | Chunking strategy key |
| `embedding_model` | str | `minilm` or `pubmedbert` |
| `k` | int | Retrieval depth (3, 5, 8, or 10) |
| `answer` | str | Generated answer text |
| `answer_relevance` | float | Cosine sim(query, answer) |
| `reference_similarity` | float | Cosine sim(answer, reference_answer) |
| `faithfulness` | float | Token overlap(answer, retrieved_context) |
| `retrieval_recall` | float | Fraction of gold doc IDs retrieved |
| `context_words` | int | Total words in retrieved context |
| `latency_ms` | float | Wall-clock ms from query to answer |
| `prompt_tokens` | int | Tokens sent to Groq |
| `completion_tokens` | int | Tokens generated by Groq |

## Resuming an interrupted run

The experiment runner checkpoints every 500 rows to `all_results.csv`. If interrupted,
re-run with the same command — completed `run_key` values are skipped automatically.
